Почта в браузере

Вся почта.
В одном месте.

Читайте письма и управляйте подключёнными ящиками во всплывающем окне браузера. Нужно больше места — откройте отдельную вкладку.

Подключайте Gmail, Яндекс Почту и Mail.ru через вход в почту в этом браузере, а JMAP — по API-токену. Для Gmail также доступно отдельное подключение каждого ящика через Google API.

Первый релиз в Chrome Web Store и публичная верификация Google OAuth готовятся. Вход через Google API пока доступен только одобренным тестовым пользователям. Outlook / Microsoft 365 в этой сборке недоступен.

Общие входящие

Подключённые ящики, папки, счётчики непрочитанных, закреплённые письма и уведомления в одном клиенте.

Чтение и действия

Открывайте переписки, меняйте состояние прочтения, архивируйте или переносите выбранные письма в Корзину.

Поиск по почте

Ищите по истории на сервере для поддерживаемых подключений. Для поиска по истории Gmail нужен Google API; подключение Gmail через браузер не поддерживает встроенный поиск по истории.

Ваши данные

Напрямую к почтовому сервису.

У mailchecker нет своего сервера, рекламы, аналитики и телеметрии. Запросы идут из браузера напрямую в подключённый почтовый сервис. Настройки, учётные данные и загруженная почта хранятся в профиле браузера. Кеш ускоряет открытие уже загруженных писем, но не скачивает всю историю и не шифрует профиль браузера.

Доступ к Google позволяет читать и искать письма Gmail, просматривать папки, менять состояние писем, переносить их в Корзину и отправлять ответы. Каждый Gmail-ящик подключается с отдельным разрешением. Набор действий зависит от провайдера; если ответ не поддерживается, открывается веб-почта.

HTML писем очищается и показывается в изолированном окне чтения. Внешние изображения заблокированы, пока вы не разрешите их загрузку. Очистить кеш почты или отключить ящик можно в Настройках.
