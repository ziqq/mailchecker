Вход через Google и Microsoft

Только для сборки расширения: подключение «Через Google» и Outlook.

Эти способы работают, когда в сборку вписан Client ID (src/background/oauth/config.ts). Создайте OAuth-клиент в Google Cloud или Microsoft Entra и укажите в нём адрес возврата ниже. Ящики, подключённые через браузер, этого не требуют.

  • Без сервераЗапросы идут напрямую в API почты.
  • Без паролейВход на страницах Google и Microsoft.
  • Только локальноТокены хранятся в профиле браузера.
